# Goals.md — v1 MVP (Frozen)

## Include
- DOCX import → best-effort parse into section tree
- Manual outline fix: promote/demote, rename, reorder, merge
- Section editor (boring blocks): heading, paragraph, list, image
- Minimal inline marks: bold / italic / link
- Section statuses: Not started → Draft → In review → Verified (+ Reopen w/ reason)
- Comments: section-level only (no anchors in v1)
- AI presets (section-only) returning blocks (or markdown → converted)
- DOCX export via template style mapping (must-match official template)
- Audit log for key actions

## Exclude
- PDF import, OCR, scanned docs
- Real-time multi-cursor collaboration
- Block-level comment anchoring, suggestion mode/track-changes
- Editable tables (v1: NOT editable)
- Rich formatting (fonts/colors/custom spacing)
